## Reporting standard

Every report includes:

- Executive summary
- Scope and assumptions
- Evidence inventory
- Timeline in UTC
- Indicators and observables
- Analysis and confidence level
- Containment and recovery recommendations
- Lessons learned

Use only synthetic, public, or self-generated evidence. Do not publish victim data, malware samples, credentials, school files, or copied solution guides.

## Framework alignment

Cases may reference NIST incident response concepts and MITRE ATT&CK techniques, but claims should be linked to public sources and written in original language.
