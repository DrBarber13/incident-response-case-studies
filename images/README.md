# Public-evidence policy

The case studies use fictional timelines, decision diagrams, and evidence tables instead of original coursework screenshots or raw captures. This preserves investigative reasoning without exposing identities, hostnames, addresses, hashes, victim information, or lab-provider material.

Any future image must be independently generated and must add analytical value that cannot be communicated safely in text or Mermaid.
# Image checklist

If this case is independently recreated, add only sanitized images of:

- Evidence inventory and hashes for newly generated files
- Redacted packet analysis
- Benign process and socket monitoring
- A timeline using fictional identifiers

Never add the original coursework screenshots, raw packet captures, personal data, malware samples, or lab-provider material.
