# Incident-Report Documentation Standard

Every report in this repository includes:

- source classification and completion status;
- severity with a stated rationale;
- UTC or explicitly relative times;
- an executive summary covering impact and disposition;
- scope, assumptions, and lab limitations;
- an evidence inventory with handling notes;
- a timeline separating events from analyst interpretation;
- findings that distinguish facts, hypotheses, and confidence;
- proportional containment, eradication, and recovery actions; and
- lessons learned and detection improvements.

Reports use fictional, synthetic, public, or self-generated evidence. They never contain victim data, credentials, malware samples, school worksheets, private infrastructure details, or copied solution guides.
